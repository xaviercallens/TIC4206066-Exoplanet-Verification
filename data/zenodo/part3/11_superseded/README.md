# 11_superseded: values that must not be quoted

`SUPERSEDED.md` lists every superseded result that concerns a number printed in the Note. For each one it gives:
- the old value;
- where it appeared;
- what replaced it, with the `FINAL_FACTS.csv` fact id;
- why it changed.

It also has a few package-specific notes, for copied files that still show older values.

When a copied REPORT.md or result file disagrees with `../12_facts/FINAL_FACTS.csv`, FINAL_FACTS is authoritative.
